# 博客页面与内容维护

## 页面结构

网站仅使用亮色。主导航固定为首页、关于、文章；首页为全宽落日封面、全部分类卡片和简短个人介绍的上下布局；具体文章列表与筛选保留在文章页。首页不再逐篇列文章、显示分页或下滑提示。内页导航与页面使用相同底色，不设独立白色条带或分隔线；首页封面桌面约占 88% 视口高度，手机约占 86%，并按屏幕尺寸设置最小和最大高度。页眉名称不带装饰圆点，页脚只保留站点名和版权；GitHub、邮件、bilibili 三个图标入口放在首页个人介绍的学院名称下方；诗句只在首页封面展示。关于页保留 `_tabs/about.md` 的原有介绍，论文改用图文条目。关于页简介头部仅保留头像、姓名与英文名；个人介绍、正文与论文区英文使用 Education 标题的衬线字体栈；左上角字标保留原无衬线字体。关于页正文桌面 18px、手机 17px，论文作者 16px、简介 17px；这些设置不影响其他页面。

全部文章仍由 `_posts/` 的真实 Markdown 渲染，默认永久链接继续使用 `/posts/:title/`。正文通过 Chirpy 的 `refactor-content.html` 处理表格、图片、代码和标题锚点，页面外壳及交互独立维护，不加载旧主题的界面脚本。代码高亮、行号、复制，MathJax 的 physics 与自定义宏，以及原 Giscus Discussions 配置均保留。

`_plugins/blog_catalog.rb` 从 Jekyll 的文章对象生成完整目录和全文索引 `/assets/data/posts.json`。增加文章后重新构建即可接入。文章页的即时筛选匹配标题、摘要与分类，保留占位文字为“搜索”的输入框；全站右上角搜索入口和独立搜索弹窗已移除。文章页不显示介绍句或常读分类快捷按钮，全部分类通过浅色中性样式下拉菜单选择。菜单增强原生 `select`，显示全部文章与全部真实分类；选中项使用浅灰米色底和深色文字，隐藏内部滚动条外观并保留滚动功能；键盘支持方向键、Home/End、Enter 和 Escape，点击外部或移出焦点关闭。禁用 JavaScript 时保留原生选择控件与完整文章列表。筛选值、URL 查询和重置操作共用同一状态，显示文本与结果同步。

两门软件工程课程的原始分类名分别含 `Ⅰ` 与 `ⅠⅠ`，筛选使用完整原名；首页卡片与文章筛选的显示文本把 `ⅠⅠ` 合并为单个 `Ⅱ` 字符，避免字体拉开两个罗马数字。旧分类路径恰好相同时，兼容页面合并展示两门课程的文章。新入口始终使用 `/articles/?category=原始分类名`。

## 首页分类卡片

首页从 `site.data.blog_catalog.categories` 渲染所有真实分类，名称、顺序与篇数来自实际文章。每张卡片背面列出该分类最近的最多六篇真实文章，点击标题直接进入文章；底部“查看全部”进入 `/articles/?category=完整分类原名`。`_data/category_covers.yml` 保存封面、原图片和页面来源；图片随 `assets/img/categories/` 本地发布。优先使用该分类文章中的现成结构图；原文无图或图片不适合缩略封面时，选择有出处的现成主题图，不自绘或把代码排版成图片。结构图完整展示，生活照片仅用于随笔。

分类卡片参考精选分类的横向 3D 翻面：桌面悬停或键盘聚焦时，0.6 秒翻到文章链接；触屏和窄屏点击封面翻看，再点文章标题进入，也可通过翻面按钮返回。禁用 JavaScript 时链接仍可进入完整文章页。减少动态效果时立即切换正反面，不播放翻转过渡。

`paginate: null` 停止生成首页文章分页。原 `/page2/` 至 `/page11/` 由插件保留为文章页的客户端跳转入口，设为 `noindex,follow` 并排除在站点地图之外；它们不是 HTTP 301，也不会继续生成重复首页。

## 论文条目

`_data/publications.yml` 统一保存三篇论文的正式标题、完整作者顺序、会议/预印本信息、简介和来源；首页不再显示论文短链接。关于页通过 `_includes/blog/publications.html` 渲染，桌面左图右文，手机上下排列，自己的名字加粗，共同一作按论文原文标注。ViDiC 使用会议官方作者顺序与 `NeurIPS 2026` 写法；CoVEBench 标为 `arXiv 2026`，不推测录用会议。

主图来自原论文或官方项目，原样保存在 `assets/img/publications/`，点击可放大；图源与元数据来源一并记录在数据文件中。关于页直接输出 Markdown 渲染结果与该组件，不再经过主题的图片 CDN 改写，保证本地图随部署发布；文章正文仍保留原有转换流程。

## 视觉与动画

头像继续引用原始 `assets/img/favicons/head.png`。首页封面使用用户提供的横图 `7.png`，原样保存为 `assets/img/cover-sunset.png`，通过 CSS 适配桌面与手机裁切。页面采用从封面提取的暖橘强调色、淡杏色和近白底色，正文保持暖中性深色；核心样式位于 `assets/css/blog.scss`。封面头像与文字组居中略向上布置，头像桌面 128px、手机 104px。标题为 HEYWEEN's Blog，与诗句一起采用包参谋慧庭手写体官方 3.0 版生成 SVG 轮廓；诗句桌面并排、手机分两行，HTML 保留标题与完整诗句供辅助技术读取。本站不分发字体文件；SVG 字形随仓库保存，正式构建和访客浏览均不依赖本机字体。仅重新生成字形时需要本地字体和 fontTools，可用 `python3 tools/render-hero-poem.py --font /本地字体路径/BaoCanMouHuiTing-Regular.ttf` 重新生成字形。字体来自[包参谋官方仓库](https://github.com/baocanmou/baocanmou-huiting)，采用 SIL OFL 1.1，许可证保存在 `assets/credits/baocanmou-huiting-OFL.txt`。

`_includes/blog/capybara.html` 保留经用户确认的手绘骑鱼动画：暖焦糖色卡皮巴拉骑着萨卡班班甲鱼向右冲刺。原始本地 `assets/img/capybara-sprint.webp`、0.64 秒帧序和镜像方向均保持不变，默认 `#intro-preview` 继续播放它；首页“放松一下”（`#relax`）每次打开均从六种动画中重新随机选择一种并持续循环，同一次打开期间不切换动作。

自动页面加载从六种动画中均匀随机选一种：抱鱼互动、吸管喝鱼杯、吃西瓜、小鱼漂水睡觉（均为 4×2 八帧精灵表，前三种 1 秒一轮、睡觉 1.6 秒一轮），卡皮巴拉和小鱼一起转圈（头追尾、体量接近、两端留空，CSS 连续旋转，在博客中的宽度为其他动画的 60%），以及原骑鱼动画。转圈鱼脸的两个小鼻孔位于灰色区，下方使用独立的倒三角嘴。睡觉场景把水层和鱼层分开：水域从画布约 32% 延伸至 94%，鱼外轮廓以外保持透明；八帧按鱼身定位，排除伸缩鼻泡的影响，整鱼以 5.6 秒缓慢往返漂移；鼻泡和 ZZZ 在每帧都存在，并以独立的 1.6 秒周期变化位置。五种新素材由 imagegen 按用户录屏动作及已确认角色的暖色手绘风格生成，保存在 `assets/img/loaders/`；骑鱼继续使用原图。一次加载固定一种动作，不在循环中重新抽签；原生站内导航通过带目标地址、时限和令牌的 sessionStorage 记录把选中动作交给目的页，并在消费、显式取消、过期或缓存恢复时清理；8 秒兜底仅关闭遮罩，有效记录保留至目的页消费或 30 秒过期。仅下载和解码当前选中的资源，存储不可用时正常退回本页随机，图片解码失败时退出遮罩。

加载动画覆盖原生站内页面跳转、页面资源与首屏图片解码；同页锚点、即时筛选和新窗口不触发整页遮罩。不人为延长等待，加载完成即收起，保留超时兜底；画面只显示动画，没有额外文案、按钮或字标。`?loader=fish-hug#intro-preview` 等地址可持续预览指定新动作，合法值为 `fish-hug`、`fish-sip`、`watermelon`、`together-spin`、`relax`、`fish-sleep`，无效值回落到骑鱼动画；通过 Escape 或点击空白处关闭。手动预览、页面加载和离站导航分别管理状态，加载完成不会误关手动预览，关闭后恢复原焦点。减少动态效果时跳过自动加载动画，手动预览显示静态帧；弹层打开时将背景设为 inert 并管理焦点。封面底部三层波浪周期分别为 10.4、13.6、17.2 秒，减少动态效果时停止流动。

页面过渡使用本地 Anime.js 4.5.0（MIT），来源为官方仓库 <https://github.com/juliangarnier/anime/tree/v4.5.0>，许可证随文件保留在 `assets/vendor/animejs/`。移除该库时，正文和导航仍可工作，脚本会跳过过渡。

分类卡片桌面采用两列；900px 以下将个人介绍移到分类区之后，避免平板宽度的卡片过窄；620px 以下改为单列。首页个人介绍保留原头像、姓名、学院和“关于我”，其下提供“放松一下”动画入口，两个入口前分别使用 imagegen 生成的卡皮巴拉头与萨卡班班甲鱼头小图标，随 `assets/img/icons/` 本地发布；文字字体与“文章分类”标题一致；移除学习句、论文短区和末尾寄语。三个社交图标使用 Font Awesome Free 6.7.2 原始 SVG，许可保存在 `assets/credits/fontawesome-LICENSE.txt`，出处保留在图源资料页。首页不显示“封面图源”入口，原始图源和许可资料仍随站点保存。

文章页阅读框最大宽度 1280px，正文列最大 840px，桌面目录列 220px、间距 88px；目录保持 sticky，名称统一为“目录”，隐藏目录滚动条与左侧装饰线。正文桌面 18px、手机 17px，代码分别 14px、13px，表格与代码仍在各自区域内横向滚动。900px 以下改为折叠目录，为正文保留可读宽度。

## 缓存与旧主题

不再注册离线 worker。根目录 `sw.min.js` 保留在原发布路径用于退休旧 worker，只移除可以确认属于本站的旧 Chirpy 缓存并注销自身，不干预同域其他项目。`_plugins/blog_theme_assets.rb` 只排除来自主题 gem 的旧界面 bundles 与默认 404，保留本地替代文件，避免相同输出路径冲突。

旧终端布局、切换入口、相关样式、旧分类以外的索引入口已移除；索引元数据不再发布已取消的分类维度。

## 验证与发布

```sh
JEKYLL_ENV=production bundle exec jekyll build
bundle exec htmlproofer _site --disable-external
```

在仓库目录执行构建，确保原有 Git 最后修改时间插件能读取历史。GitHub Actions 在 Linux 构建后发布。

已有两篇文章的永久链接仅大小写不同：`/posts/OVERVIEW/` 与 `/posts/overview/`。保留它们原有地址。本地预览全部文章时，输出目录必须位于区分大小写的文件系统；默认 macOS 卷会将两份输出覆盖为同一文件。Linux 的 CI 输出可分别保留两篇。

外部图片、MathJax CDN 与 Giscus 需要网络；内部链接检查不代表所有外部资源永久可用。
